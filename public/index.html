Empat cara menerima pembayaran dengan Kasera Pay

Situs ini adalah toko demo yang benar-benar berjalan sekaligus contoh integrasi Kasera Pay — pembayaran QRIS untuk merchant Indonesia lewat halaman checkout yang di-host Kasera. Anda membuat payment request, Kasera memberikan tautannya, pembeli memindai dan membayar, lalu Anda diberi tahu (atau bertanya sendiri) saat uangnya masuk. Toko kaosnya, Kasera Threads, dibangun empat kali — satu untuk tiap cara integrasi, dari tanpa kode sama sekali sampai alur webhook penuh.

CASE 0
Tanpa API sama sekali

Buat tautan pembayaran dari dashboard dan bagikan. Nol kode.
CASE 1
Redirect saja

Backend Anda membuat payment request lalu mengarahkan pembeli ke checkout. Pemakaian API paling sederhana.
CASE 2
Webhook

Kasera memanggil server Anda begitu pembayaran masuk — bertanda tangan, terverifikasi, at-least-once. Cara produksi.
CASE 3
Polling

Server Anda bertanya ke Kasera "sudah dibayar?" sampai terjawab. Tanpa URL publik — pas untuk pengembangan lokal.

Cara demo ini dibangun

Satu file Go (main.go, hanya stdlib) plus halaman statis di public/ — HTML polos, vanilla JS, satu file CSS. Tanpa framework, tanpa build step, tanpa npm. Baca sumbernya dari atas ke bawah dan Anda sudah membaca seluruh integrasinya.
